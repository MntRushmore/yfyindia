## ✨ About

**Shree Krishna** is an immersive, scroll-driven website dedicated to the divine love story of **Radha and Krishna**. Built entirely with vanilla HTML, CSS, and JavaScript, it features cinematic GSAP animations, smooth Lenis scrolling, and a built-in music player — all woven together to create a spiritual digital experience.

---

## 🎨 Features

| Feature | Description |
|---|---|
| 🎬 **GSAP Animations** | Scroll-triggered reveals, parallax effects, and smooth transitions |
| 🎵 **Music Player** | Built-in Spotify-style player with cross-page sync |
| 🖼️ **Art Gallery** | High-quality divine artworks with one-tap download |
| 📖 **Story Chapters** | Four chapters covering Divine Love, Raas Leela, Separation & Eternal Union |
| 🔄 **Page Transitions** | Cinematic overlay transitions between pages |
| 📱 **Responsive** | Fully responsive across all devices |

## 🎵 Built-in Music Player

A floating Spotify-style music player lives on every page:

- 🎶 Plays *"Shri Krishna Govind Hare Murari"* by Simpal Kharel
- advancement across pages using `sessionStorage`
- 🔗 Direct link to the track on Spotify
- advancement bar with drag-to-seek support (mouse + touch)
- 🔁 Auto-opens with "Play Again?" prompt when the song ends

## 🚀 Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, animations, responsive design
- **JavaScript** — Vanilla ES modules
- **[GSAP](https://gsap.com)** — ScrollTrigger animations
- **[Lenis](https://lenis.darkroom.engineering)** — Smooth scroll
- **[Vite](https://vitejs.dev)** — Dev server & build tool
- **Vercel** — Deployment

## 🏗️ Getting Started

```bash
# Clone the repository
git clone https://github.com/Atharvsinh-codez/Shree-Krishna.git

# Navigate into the project
cd Shree-Krishna

# Install dependencies
npm install

# Start the dev server
npm run dev
```
